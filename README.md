# SelfMaster v2.0 🚀

**Застосунок для відстеження звичок, цілей та особистого розвитку**

## Встановлення та запуск

```bash
# Вимоги: Python 3.8+, tkinter (вбудований в Python)
# Опційно (для графіків): pip install matplotlib

python main.py
```

## Що нового в v2.0

- ✨ **Повністю новий дизайн** — темна тема, акцентні кольори
- 🗄️ **Локальна БД** — SQLite без зовнішніх залежностей (`~/.selfmaster/data.db`)
- 🐛 **Всі баги виправлено** — збереження даних, streak розрахунки
- ⚡ **Чистий Python** — тільки стандартна бібліотека (sqlite3 замість SQLAlchemy)
- 🎨 **Hover ефекти** на всіх кнопках
- 📊 **Статистика** — з matplotlib або без (fallback)

## Структура файлів

```
selfmaster/
├── main.py          # Точка входу
├── config.py        # Налаштування  
├── db.py            # База даних (SQLite)
├── theme.py         # Кольори та шрифти
├── widgets.py       # Реюзабельні компоненти
├── tab_today.py     # Вкладка "Сьогодні"
├── tab_month.py     # Місячна сітка
├── tab_stats.py     # Статистика
├── tab_ideal.py     # Ідеальна людина
├── tab_habits.py    # Керування звичками
└── tab_goals.py     # Цілі
```

## Де зберігаються дані

`~/.selfmaster/data.db` — SQLite база даних
