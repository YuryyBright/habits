# SelfMaster — Інструмент для покращення себе

Десктопний застосунок для відстеження звичок, цілей та прогресу до ідеальної версії себе.

## Можливості

| Вкладка | Опис |
|---------|------|
| 📅 **Сьогодні** | Щоденне логування звичок (✔/✖ або число), оцінка себе, щоденник |
| 📊 **Місяць** | Повна таблиця-сітка за місяць з тепловою картою |
| 📈 **Статистика** | Графіки прогресу, порівняння звичок, динаміка настрою |
| 🌟 **Ідеал** | Критерії ідеальної людини (фізичне, ментальне, соціальне...) |
| ⚙️ **Звички** | Додавання/редагування/видалення звичок |
| 🎯 **Цілі** | Постановка цілей з дедлайном та прогресом |

## Запуск

### Варіант 1 — Пряме запуск (Python)
```bash
pip install matplotlib
python main.py
```

### Варіант 2 — Збірка .exe (Windows)
```batch
build.bat
```
або вручну:
```bash
pip install matplotlib pyinstaller
pyinstaller selfmaster.spec --clean --noconfirm
# Готовий файл: dist/SelfMaster.exe
```

## Дані
Всі дані зберігаються в SQLite базі:
- Windows: `C:\Users\<ім'я>\.selfmaster\data.db`
- Mac/Linux: `~/.selfmaster/data.db`

## Структура файлів

```
selfmaster/
├── main.py              # Головний файл — запускати звідси
├── requirements.txt     # Залежності (тільки matplotlib)
├── selfmaster.spec      # Конфіг для PyInstaller (.exe)
├── build.bat           # Скрипт збірки Windows
├── db/
│   ├── database.py     # Ініціалізація SQLite бази
│   └── queries.py      # Всі запити до бази (CRUD)
└── ui/
    ├── theme.py        # Кольори та стилі
    ├── widgets.py      # Перевикористовувані віджети
    ├── tab_today.py    # Вкладка "Сьогодні"
    ├── tab_month.py    # Вкладка "Місяць"
    ├── tab_stats.py    # Вкладка "Статистика"
    ├── tab_ideal.py    # Вкладка "Ідеал"
    ├── tab_habits.py   # Вкладка "Звички"
    └── tab_goals.py    # Вкладка "Цілі"
```

## Типи звичок

- **Так/Ні** — просте виконання (✔ виконано / ✖ ні)
- **Числове** — кількість (сторінки, склянки, хвилини...)
  - Позитивна звичка: більше = краще (читання, вода, спорт)
  - Негативна звичка: 0 = ідеально (куріння, соцмережі)

## Критерії ідеальної людини

Оцінюй себе за шкалою 0–5 щодня:
- 0 — Нічого не зробив
- 1 — Слабко  
- 2 — Нижче норми
- 3 — Нормально
- 4 — Добре
- 5 — Відмінно

Категорії: Фізичне, Ментальне, Соціальне, Фінансове, Духовне, Інше
